# Eletromax V2 MVP

Painel inicial para organização de ofertas e automação de divulgação da Eletromax.

## Estrutura
- `frontend/` painel web responsivo
- `backend/` API Node.js/Express para receber e organizar ofertas
- `config/` exemplos de configuração
- `docs/` documentação e próximos passos

## Como executar
1. Instale Node.js 20+.
2. Entre em `backend` e execute `npm install`.
3. Execute `npm start`.
4. Abra `frontend/index.html` no navegador.

## Observação
Este MVP não contém credenciais reais nem automação de publicação autenticada. Para integrar Mercado Livre, Shopee, WhatsApp ou Instagram, configure as APIs oficiais e credenciais próprias.
