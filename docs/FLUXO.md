# Fluxo planejado

1. Captar/receber link de produto.
2. Cadastrar oferta no painel.
3. Validar título, preço e link.
4. Gerar texto de divulgação.
5. Escolher canal: Mercado Livre, Shopee, WhatsApp ou outros canais permitidos.
6. Enviar para aprovação ou publicação via APIs oficiais.
7. Registrar status e histórico.
